# 用本倉庫規劃旅行

本專案目前的正式資料入口：

https://github.com/Khoohew/Shanxi-Ancient-Architecture

規劃山西古建旅行時，請優先讀取最新 `main` 分支中的：

- `data/sites.csv` 或 `data/sites.json`：全部地點與原始座標；
- `data/city-index.md`：按城市查找地點及文物保護級別；
- `places/README.md`：逐點研究檔案索引；
- `maps/`：全量及分城市 KML 地圖；
- `sources/README.md`：斷代來源與研究規範；
- `research-progress.md`：目前研究進度及下一批編號。

## 規劃時仍須即時查驗

GitHub 是歷史知識與位置線索資料庫，不會自動提供即時狀態。每次出行前仍須確認：

- 當天是否開放、臨時閉館或施工；
- 是否需要預約、票價、餘票及景區接駁；
- 村內、學校、寺院看護區域或私人院落是否允許進入；
- 山路、停車位置及最後一段步行路線。

## 研究資料使用提醒

- `source_confidence` 是桌面資料證據等級，不是文物保護級別。
- 寺院始建年代不等於現存殿堂、塔、彩塑或壁畫的年代。
- 原始座標尚未全部完成專業座標轉換及現場核位；精確導航請另行核對。
- 有年代衝突的點位應同時保留各說法及來源，不應只取一個看似確定的年份。
