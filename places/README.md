## 檔案維護說明

- 每批按原始 CSV 順序研究，保留原始名稱及座標。
- 寺院創建、現存建築、碑刻、造像、壁畫及維修年代分開判斷。
- 來源存在矛盾時保留不同說法，不把推測寫成定論。
- 桌面研究不等於現場踏查；開放狀態、入口及進入權限須另行核查。
