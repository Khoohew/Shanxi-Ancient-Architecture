# 資料來源與研究規範

## 來源優先級

1. 國家文物局、文化和旅遊部、國家級/省級文物主管部門、文物保護單位管理機構。
2. 市縣人民政府、文旅局、博物館和考古/文博專業機構。
3. 正式發表的建築史、考古、文物保護研究論文與正式調查報告。
4. 高校和專業研究機構發佈的教學/研究資料。
5. 可靠媒體的專題報道，僅用於線索與補充，不單獨承擔關鍵斷代。

旅遊平臺、用戶地圖、百科和社交媒體可用於發現地點，但不應成爲唯一斷代證據。

## 來源審查規則

- 記錄標題、發佈機構、日期、URL、覈查日期。
- 儘可能引用原始政府/博物館/高校頁面，而非轉載。
- 關鍵斷代至少有一條足以支持對象和年代的來源；爭議年代並列呈現。
- 動態開放、票務、預約信息須記錄“覈查日期”，原則上出發前7天重新覈對。
- 圖片、圖紙、掃描資料應遵守版權；優先鏈接原頁面，不復制整篇文章。
